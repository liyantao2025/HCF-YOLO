# Complete experimental archive

The default branch is intentionally kept small and contains only the proposed HCF-YOLO11n model, the YOLO11n baseline, selected checkpoints, and the scripts required for setup, training, evaluation, and prediction.

The complete pre-cleanup reproducibility package—including ablation configurations, external-validation manifests, localization/counting scripts, pruning and quantization scripts, Raspberry Pi deployment artifacts, machine-readable result files, and integrity records—is preserved at Git tag:

```text
full-reproducibility-v1
```

To retrieve it:

```bash
git checkout full-reproducibility-v1
```
